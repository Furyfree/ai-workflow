# Codex adapter

- Codex project instructions are discovered through `AGENTS.md`; follow the
  closest applicable file when instructions differ.
- User skills are installed under `~/.agents/skills` unless `AGENTS_HOME`
  selects another location.
- Invoke a skill explicitly with `$skill-name` when automatic selection is
  uncertain.
- Keep Codex configuration, models, MCP servers, rules, trust, sandbox, and
  approval policy outside this workflow package.
