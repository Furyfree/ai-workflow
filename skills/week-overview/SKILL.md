# Week overview

Give the overview in chat. Do not quiz, solve exercises, or edit notes.
Use `study` once the user asks to start learning or practising.

## Find the assigned material

- Read the repository's AGENTS.md and relevant course instructions. Use the
  course plan and week folder to find the reading, slides, exercises,
  supplied code, and board photos.
- Ask which course or week only if the conversation leaves it unclear.
- Check the teacher's assigned sections and tasks against the source files.
  Use existing notes to locate material, not as proof of what the teacher
  expects. Report missing files and conflicting schedules.

## Read before summarising

- Use `document-analysis` for PDFs and document images. Read the assigned
  textbook sections and the whole lecture deck. Inspect supplied code and
  board photos that explain the week's topics.
- Locate textbook sections by their headings. Record printed page numbers
  and PDF page numbers; do not assume they match.
- Slide decks may contain several PDF pages for one numbered slide as
  content appears in steps. Group pages by slide number and read the final
  version. Check earlier versions if they contain content the final one
  omits. Cite slide numbers and the corresponding PDF pages.
- Inspect screenshots for diagrams, formulas, code layout, handwriting,
  and garbled extraction. Use text for clear prose; do not screenshot
  duplicate slide builds without a reason.
- Report which pages you checked by vision and any unreadable or unreviewed
  material. Do not claim complete coverage if you could not read it all.

## Give one overview

Name the course and week, then keep these parts short:

1. **Read:** the teacher's assigned sections and page ranges, with source
   links. Separate extra reading you suggest from assigned reading.
2. **Learn:** the week's concepts in the course's terms. Connect the book's
   explanation to the lecture's examples rather than listing headings.
3. **Be able to do:** concrete actions linked to exercises and sources,
   such as tracing an evaluation, explaining a type, or choosing a method.
   Include the assigned tasks without giving their solutions.
4. **Study order:** a route through the reading, examples, and tasks, with
   prerequisites first. Label this as your recommendation.

Attach a file link and section, slide, or page reference to each learning
point and task. Distinguish the teacher's explicit requirements from skills
inferred from examples and exercises. Claim exam relevance only when a
course source supports it. End with coverage gaps, if any; wait for the user
before starting tutoring.
